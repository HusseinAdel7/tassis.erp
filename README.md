# موقع تأسيس | Tassis ERP Official Showcase Website

الموقع التعريفي والتسويقي الرسمي لمنظومة **تأسيس (Tassis ERP)** لعرض سابقة الأعمال، تسويق المنظومة للعملاء، وتوفير كافة قنوات الاتصال وحجز العروض التجريبية المباشرة (Live Demos).

---

## 📁 هيكلية المشروع (Project Structure)

```text
tassis-website/
├── index.html            # الصفحة الرئيسية والتسويقية (Landing Page)
├── features.html         # دليل الموديولات والمميزات التفصيلية
├── portfolio.html        # معرض الأعمال والخبرات البرمجية
├── contact.html          # صفحة التواصل وحجز موعد ديمو
├── assets/
│   ├── css/
│   │   └── style.css     # تصميم عصري متجاوب بتقنيات SaaS الحديثة وخطوط Cairo & Tajawal
│   ├── js/
│   │   └── main.js       # التفاعلات: القوائم، التابات، الأكورديون، والربط بالواتساب
│   └── images/
│       └── brand/        # أيقونات وشعارات الهوية الرسمية (logo.png, icon.png, favicon.ico)
└── README.md
```

## 🚀 كيفية تشغيل الموقع

الموقع مبني بتقنيات الويب القياسية (HTML5 / Modern CSS3 / Vanilla ES6 JavaScript)، ولا يتطلب أي تثبيت لمكتبات معقدة:
1. **التشغيل المباشر:** يمكنك النقر المزدوج على ملف `index.html` لفتحه مباشرة في أي متصفح (Chrome, Edge, Firefox, Safari).
2. **الاستضافة السحابية:** جاهز للرفع المباشر على أي استضافة مثل:
   * GitHub Pages
   * Vercel
   * Netlify
   * أي خادم استضافة ويب (CPanel / Nginx / Apache / IIS).

---

## 🌟 أبرز مميزات الموقع
* **عربي أصيل (RTL-First):** خطوط عربية فاخرة وقراءة مريحة.
* **متجاوب 100% (Mobile Responsive):** تجربة مثالية على الجوالات، الأجهزة اللوحية، وشاشات الحواسيب المكتبية.
* **ربط مباشر مع واتساب:** حقول نموذج الديمو تقوم بصياغة رسالة واتساب جاهزة ببيانات العميل واسم شركته لفتح المحادثة الفورية بضغطة واحدة.
* **معرض أعمال متكامل:** تسويق لمنظومات الحسابات، الكاشير والمطاعم، المستشفيات والعيادات، المخازن والباركود، والفاتورة الإلكترونية.
